## 📌 1. Назначение и Концепция Проекта

**FamilyBook** — это изолированное семейное веб-приложение (PWA) и социальная сеть с возможностью безопасной демонстрации для новых пользователей через **Гостевую песочницу (Guest Sandbox)**.

### Основные функции:
- 📖 **Семейная лента постов:** публикация историй, фотографий, реакций-эмодзи и комментариев.
- 🏝️ **Гостевая песочница (Guest Sandbox):** сессия на 30 минут со сбросом данных и изоляцией от основных семейных записей.
- 📅 **Семейный календарь:** события, дни рождения и памятные даты.
- 📱 **PWA & Оффлайн-режим:** установка на смартфон/ПК, оффлайн-кэширование, WebPush-уведомления.
- 🛡️ **Антиспам и Безопасность (Sentinel):** автоматическая фильтрация XSS, защита от брутфорса, Telegram-оповещения администратора об аномалиях.

## 🏗️ 2. Архитектура и Технический Стек

| Компонент | Технология | Почему именно эта технология? (Decision Rationale) |
|---|---|---|
| **Backend Framework** | **FastAPI** (Python 3.12) | Высочайшая скорость работы, встроенная валидация Pydantic v2, родная поддержка `asyncio` и WebSockets. |
| **ORM & Database** | **SQLModel** (SQLAlchemy 2.0) | Объединяет преимущества Pydantic и SQLAlchemy. Работает со SQLite в dev и PostgreSQL в prod. |
| **Frontend Architecture** | **Jinja2 + HTMX + Alpine.js** | **No-SPA архитектура.** Позволяет строить быструю реактивную PWA без сложности React/Vue, компиляции и сборщиков JS. |
| **CSS Framework** | **Tailwind CSS + Vanilla CSS** | Гибкая кастомизация, поддержка тёмной темы (`dark:`), стеклянных эффектов (Glassmorphism) и системных CSS-переменных. |
| **Background Tasks** | **Celery + Redis** | Асинхронная отправка утилитных задач, обработка тяжелых операций и отправка Push-уведомлений. |
| **Push Notifications** | **PyWebPush + Service Worker** | Прямая доставка Push на мобильные устройства iOS (iOS 16.4+) и Android по стандарту VAPID. |
| **Контейнеризация** | **Docker + Docker Compose + Nginx** | Изоляция сервисов, легкое развертывание с автоматическим выпуском SSL-сертификатов Certbot. |

## 💡 3. Принятые Ключевые Технические Решения (ADR)

### 3.1. Почему отказались от React/Vue в пользу HTMX + Alpine.js?
* **Контекст:** Семейному приложению нужна высокая отзывчивость (лайки без перезагрузки, динамическое добавление комментариев, анимация модальных окон).
* **Альтернатива:** Отдельный frontend на React / Next.js и REST API.
* **Решение:** Выбран **HTMX + Alpine.js + Jinja2**.
* **Причина:**  
  1. Избавляет от необходимости поддерживать два разных репозитория (frontend и backend).
  2. HTML фрагменты рендерятся на сервере (SSR) за единицы миллисекунд и вставляются в DOM через HTMX.
  3. Alpine.js обеспечивает реактивность UI (таймер песочницы, переключение тем, модальные окна) без раздувания бандла.

---

### 3.2. Почему синхронные вызовы БД обернуты в `run_in_threadpool` в `async` хэндлерах?
* **Контекст:** SQLModel/SQLAlchemy использовала синхронный движок `Session(engine)`. При вызове в асинхронных роутах `async def` синхронные запросы блокировали главный поток `asyncio` Event Loop.
* **Решение:** Обернуть вызовы к базе данных в `await run_in_threadpool(...)` из Starlette/FastAPI.
* **Причина:** Это позволило **разблокировать Event Loop** при высокой конкурентности без проведения рискованного глобального рефакторинга всего проекта на `AsyncSession`.

---

### 3.3. Как устроена Гостевая Песочница (Guest Sandbox)?
* **Контекст:** Нужно давать сторонним людям протестировать приложение, не компрометируя при этом личные фотографии семьи.
* **Решение:**  
  1. При входе создается временный пользователь с флагом `is_guest = True` и `expires_at = now + 30 минут`.
  2. Все запросы к ленте постов и комментариям изолированы условием `where(User.is_guest == user.is_guest)`. Гости видят только контент других гостей.
  3. Фоновый модуль `cleanup.py` автоматически удаляет просроченных гостей вместе с их созданными файлами и постами.

---

### 3.4. Архитектура PWA и Оффлайн-режима (`sw.js`)
* **Контекст:** PWA должно устанавливаться на экран смартфона и работать стабильно даже при кратковременном обрыве связи.
* **Решение:**  
  1. В `sw.js` реализованы 3 стратегии:
     - **Static Assets (CSS, JS, иконки, звуки):** `Stale-While-Revalidate` с динамическим сохранением в кэш `familybook-v4.0`.
     - **Страницы HTML (Навигация):** `Network First` с автоматическим переключением на автономную страницу [offline.html](file:///c:/Users/Mixa-/Desktop/dev/family_book/Family_Book/app/static/offline.html) при отсутствии интернета.
     - **API / Auth:** `Network Only` (без кэширования для безопасности авторизации).
  2. Добавлен `viewport-fit=cover` и CSS-переменные `env(safe-area-inset-top/bottom)` для идеальной верстки под вырезы экранов iOS (Notch / Dynamic Island).

## 🛠️ 4. Инструкция по Обслуживанию и Развертыванию

### Локальный запуск (Development):
```bash
cd Family_Book
poetry run uvicorn app.main:app --reload --port 8000
```

### Запуск через Docker (Production):
```bash
docker-compose up -d --build
```

### Миграции базы данных (Alembic):
```bash
# Создание миграции после изменения models.py
poetry run alembic revision --autogenerate -m "descriptive message"

# Применение миграций
poetry run alembic upgrade head
```
